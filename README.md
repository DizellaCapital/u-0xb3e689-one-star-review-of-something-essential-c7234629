A one-star review of the sun — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The review

> **The sun shows up late all winter, leaves early, and still expects five stars for one good sunset.**

One star. Filed in earnest against a thing that cannot be fixed: all winter the sun arrives late and leaves early, and still expects a five-star review for a single decent sunset. Deadpan throughout, the sting lands in the last few words.

## How it works

`main.py` (stdlib only) writes the review to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is a single line of 1–160 characters, and verifies the write by reading it back. The entry file is exactly 97 bytes, with no trailing newline.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
